# External evidence

## Scope and coverage

Inspect the declared scope, coverage, truncation and diagnostic before concluding that evidence is absent.

## Recover supported evidence

Narrow an incomplete search or fetch the relevant bounded continuation; correct invalid patterns against the selected engine. Provider-backed search, public fetch and document adapters have distinct availability and authorization boundaries. Use a supported source or conversion when available; do not claim that an unperformed fetch/read succeeded.

## Limits and configuration authority

A blocked URL is not permission to bypass the public-fetch boundary. State material freshness or coverage limits and avoid repeated identical failures. Configuration changes require the actual configuration path and appropriate authority.
