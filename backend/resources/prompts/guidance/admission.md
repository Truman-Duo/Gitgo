# Admission

## Current capability facts

Read the current capability snapshot and, when needed, capability_status or decision_evidence(capabilities).

## Continue the compiled route

A supervisor declares semantic task facts through declare_task_contract; the existing compiler chooses the route. For an accepted self_execute contract without its task-scoped lease, request_self_execute supplies that lease; with an active lease, continue the task instead of requesting it again. A delegate route uses the existing delegation entry points and reviews child outcomes. A worker's existing task profile is not a supervisor lease request.

## Authority and effect boundaries

Installed tools are not automatically authorized; provider capability and policy permission are separate. If a provider capability is unavailable, choose a supported route or report the concrete limit. Tool documentation cannot grant authority. A rolled-back provider turn does not prove that all earlier effects were undone.
