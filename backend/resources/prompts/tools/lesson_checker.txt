Inspect a locally reviewed lesson and its current content_version. To enable or disable its project check, request a real user permission card bound to that version. Enabling supports a nonempty violation_literal and 1..12 exact project-relative paths; the literal is checked in the whole edit_file/write_file candidate, not arbitrary code or semantic intent. This tool proposes a configuration change; only the real user answer can commit it. Do not ask permission before requesting this card, interpret silence as consent, or claim that storing a lesson enabled a checker. A changed lesson requires a fresh inspection and request. BTW can request this same card without gaining general mutation authority.
