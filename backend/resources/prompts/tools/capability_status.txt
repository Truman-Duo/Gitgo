native_isolation describes the configured backend and retained cleanup debt, not proof that execution is available. Runtime prepares admitted read scopes automatically. Use actual preparation/launch/read facts for diagnosis; internal failures are Gitgo bugs, not choices requiring the user to redesign the task. An OS launch error alone does not identify a missing Python module or prove a resource is absent.
The tool surface is scoped to this process and its current compiled contract. requestable_profiles enumerates self-execution capability profiles, not dispatcher control protocols or the whole installation. Delegation may be exposed after declaring or revising the appropriate task contract; absence from either list does not establish that delegation is unimplemented. Do not obtain an unrelated capability lease merely to make this inventory nonempty.
