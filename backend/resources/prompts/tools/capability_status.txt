Inspect current capabilities or discover active tools; this read grants no authority.
- status (default): current model, protocol and fallback status, without credentials. Use before claiming a feature is unavailable.
- catalog: paged active names and purposes; optional group, cursor and limit (1–20).
- search: lexical query, optional group; matches can be missed. Fall back to catalog without query.
- describe: one exact name returns its full current contract. Read it before the intended invocation.
Scope: current process and compiled contract only. Inactive tools cannot be described. requestable_profiles lists self-execution profiles, not the whole installation or dispatcher protocols. Delegation can appear after appropriate contract routing; absence does not prove it is unimplemented. Do not request an unrelated lease to fill the list.
native_isolation reports configuration and cleanup debt, not execution availability. Runtime prepares admitted reads. Diagnose actual preparation/launch/read facts; internal failures are Gitgo bugs. An OS launch error alone proves neither a missing module nor an absent resource.
