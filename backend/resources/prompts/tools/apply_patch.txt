Apply a bounded standard UTF-8 text unified diff inside the workspace. Each file needs --- a/path and +++ b/path headers and valid @@ -old_start,old_count +new_start,new_count @@ hunks. Use /dev/null for creation or deletion. The file service projects all candidates privately, then checks every candidate before committing any target. If advice is returned, consider it and revise or reference its lesson_feedback_id when resubmitting the whole unchanged patch. A failed commit can have partial or uncertain effects: inspect per-file results before replanning; do not blindly replay. Binary, symlink and file-mode patches are not supported by this text candidate interface. Prefer edit_file for a small exact replacement.
