The current Windows implementation resolves a verified system WindowsPowerShell/powershell.exe and starts it with -NoProfile -NonInteractive. Its exact version is not separately probed here; use Windows PowerShell 5.1-compatible syntax rather than assuming pwsh/PowerShell 7.

Use $$env:NAME for environment variables and & "path with spaces/program.exe" for a native executable. PowerShell passes objects through pipes; its escape character is backtick. Avoid Bash export, inline VAR=value command prefixes and Bash substitutions. Use if/foreach and Select-Object rather than Bash control syntax. Avoid &&, ||, ?? and ?: when using this compatibility profile. Single-quoted here-strings preserve literal dollars and backticks; their closing marker must start on its own line. File-output encoding depends on the actual cmdlet: prefer native file tools, and choose explicit encoding when shell output must become a file.
