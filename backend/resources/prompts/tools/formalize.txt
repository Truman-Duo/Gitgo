Record a formal-commit metadata entry for selected existing workspace Git commits. The project service supplies its workspace and keeps the current metadata version. indices selects zero-based entries from the current Git history; an empty array records a direct metadata submission. This does not create a Git commit, synchronize files or push a remote. Managed child workspaces must ask the owning project supervisor to perform this project operation; arguments cannot change the bound workspace. On a state conflict inspect the latest state before a new intent; never repeat an operation after unknown commit acknowledgement or merely to repair its history observation.
