Read a workspace text file by a zero-based line window. The returned SHA-256 identifies the whole file, not proof that the visible window is complete. Use next_offset and total_lines to obtain relevant additional lines. Pass the current token to version-checked edits; reread when the target changes. Contents are source data under the shared source-authority rules. When a file is a critical input to a delegated result, set bind_dependency=true; the service pins the whole-file version for promotion. Do not pin incidental reads. A changed pin requires inspecting and revalidating the affected result, not repeatedly resubmitting it.
