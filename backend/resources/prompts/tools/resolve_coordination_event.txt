Resolve a Host-routed coordination event. Interface revisions require accept_revision, request_rework, or ask_user; accepting mechanically updates the versioned interface document and releases affected downstream B Agents. This is the only route for changing a cross-B task boundary.

Use take_remaining_work when you decide to finish a direct independent workspace assignment yourself and B requested a return (coordination_request or blocked). First let that B close or stop it with cancel_agent, then wait for finalized closeout. A completed execution may still have only an unpublished draft. Supply the event ID and the reason. The returned assignment lists the original targets, acceptance requirements and private draft files. Review useful draft files with read_child_artifact, request a self-execution lease, and finish and verify the remaining work. Use complete_supervision for the parent task. An explicit requirement for an approved delegated outcome still applies.
On a draft offer, use its exact event ID. accept_draft selects the direction while B remains responsible. take_remaining_work transfers the unfinished responsibility after finalized closeout. To reassign it to a fresh B, call delegate_task with the exact draft_id after closeout. Downstream work waits for approval of B's sealed result or, if you took the work back, complete_returned_work on the same event after your own verified delivery.
