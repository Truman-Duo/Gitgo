Recoverably delete one workspace file after reading its current SHA-256. The file service checks the exact deletion candidate before moving the file into project-local .gitgo/trash and returning a restore reference and deletion diff. If advice is returned before deletion, consider it and either revise the action or reference its lesson_feedback_id to resubmit the same candidate. This reference is not user approval. Directories and .gitgo internals cannot be deleted through this tool.
