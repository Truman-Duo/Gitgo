Raise an interface question, dependency change, blocker or scope issue to your governing supervisor. Supply the concrete question or finding, evidence, affected interfaces and proposed next action. Relevant events may also reach registered downstream dependencies. The supervisor decides whether to involve another subprocess or revise the task. Delivery of an event does not accept work. Set requires_user_decision only for a real user choice.
Set offer_draft=true on a coordination_request or blocked event when the supervisor needs to inspect unfinished assigned files. The runtime freezes those files, links observed test evidence and remaining acceptance requirements, and returns an exact draft ID. You can continue working and later offer a newer version. A draft does not complete your task.
If a scope change blocks further work or the supervisor requests a draft for reassignment, offer the current files promptly before trying more effects or submitting completion. If the withdrawal is already adopted, this offer binds the draft and no further edits are accepted on the original assignment.
