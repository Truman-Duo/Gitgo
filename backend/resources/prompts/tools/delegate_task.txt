Delegate an executor-ready task contract to an independent B Agent. The host starts it asynchronously and serializes overlapping writes. Every new B escrows part of the task-tree provider/output budget. Do not delegate routine file persistence or testing after A has already derived the solution; request a self-execution lease instead. For a known dependency graph, use delegate_task_dag rather than relying on call order to represent dependencies. Inspect list_agents and the task-tree budget card before replacement or continuation; remaining_uncommitted includes protected capacity, while work_available_for_delegation is the actual child-call admission capacity. Budget rejection is not permission to reset the tree or repeat completed work.
