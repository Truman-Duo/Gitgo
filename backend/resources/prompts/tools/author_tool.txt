Manage project-saved Python shortcuts. Pure mode is statically confined. Host mode keeps pure code but supports call_tool(name, arguments) for declared host_tools; every leaf uses the canonical Host pipeline and exact permission, and resumes without replaying effects. Registration tests supply mock host_results (tool_name,arguments_digest,result); no live effects run. Privileged mode may use imports, files, processes or network, but binds the source digest and registration contract to explicit user approval, and every later invocation requires a new exact approval. register/replace creates an immutable tested version; use mounts it for this task; detach keeps the asset; delete archives it; restore reactivates it.
