### 3.4 step_scan 流程

```
step_scan():
  1. scan_workspace(workspace, exclude_patterns) → files: list[str]
  2. 如果 backup_path 是 git 仓库:
       get_git_log(workspace, sync_base) → commits
       对比 files → entries: list[FileEntry]
      (通过 compare_files → git diff 判断 new/modified/same)
  3. 如果 backup_path 不是 git 仓库:
       所有文件标记为待处理
  4. self.entries = entries
  5. self.commits = commits
  6. return entries
```

### 3.5 step_create_formal_commit 流程

```
step_create_formal_commit(selected_indices, message):
  1. 解析 message → 提取 prefix, number
  2. 去重检查 number
  3. 创建 FormalCommit(message, number, prefix, source_indices=selected_indices)
  4. self.formal_commits.append(fc)
  5. return fc
```

## 五、Adapters 适配器层

### 5.1 LocalGitRunner (backend/adapters/local_git_runner.py)

```python
class LocalGitRunner:
    def __init__(self, repo_path: Path):
        self.repo_path = repo_path

    def run(self, args: list[str], **kwargs) -> str:
        """执行 git 命令，返回 stdout"""
        result = subprocess.run(
            ["git"] + args,
            cwd=str(self.repo_path),
            capture_output=True, text=True,
            creationflags=subprocess.CREATE_NO_WINDOW if os.name == "nt" else 0,
        )
        return result.stdout

    def rev_parse(self, ref: str) -> Optional[str]:
        """获取 ref 的 commit hash"""

    def log(self, since: str = None, max_count: int = 20) -> list[dict]:
        """获取 commit log"""
```

**关键**: `CREATE_NO_WINDOW` 防止 Windows 每次 git 命令弹出控制台窗口。

## 十二、B-2: Dissolve vs Clear Sources

### 语义

| 操作 | Formal commit | Workspace commits | 连接线 | UI 表现 |
|------|--------------|-------------------|--------|---------|
| **Dissolve** | 删除 (`pop`) | `_refresh_workspace_boxes()` 刷新为新卡片（未合并） | 消失 | Workspace box 恢复可选状态 |
| **Clear Sources** | 保留，`sources_cleared=True` | `QGraphicsOpacityEffect(0.3)` + `setEnabled(False)` | 消失（`source_indices=set()`） | Workspace box 变成禁用灰色 |

### Dissolve 恢复流程 (`_dissolve_formal_commit`)

1. 检查 `fc.source_indices` 非空 → 否则提示无法 Dissolve
2. 弹出确认对话框 → 用户确认
3. `self.session.formal_commits.pop(index)` 删除 formal
4. `fc.is_dissolved = True` 标记
5. `_refresh_formal_boxes()` + `_refresh_workspace_boxes()` 刷新两侧列表
6. workspace box 以新实例创建，无合并状态

### Clear Sources 封存流程 (`_clear_formal_sources`)

1. 检查 `fc.source_indices` 非空 → 否则提示
2. 遍历 `fc.source_indices`，在 ws_box_layout 中找到对应的 `WorkspaceCommitBox`
3. `QGraphicsOpacityEffect(0.3)` + `setEnabled(False)` 禁用每张卡片
4. `fc.sources_cleared = True` + `fc.source_indices = set()`
5. `_refresh_commit_lines()` 清除连接线（source 为空）
