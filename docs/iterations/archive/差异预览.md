# 同步前差异预览

> 选中文件后显示 workspace vs backup 文本差异对比（类似 git diff），辅助用户确认变更后再同步。

---

## 界面设计

### GUI

在左侧文件列表下方增加 **差异预览面板**（QPlainTextEdit + monospace 字体），与文件列表上下分割（QSplitter）：

```
┌─────────────────────────────────────┐
│ 文件列表（单击查看差异）              │
│ [x] MODIFIED  src/main.py            │
│ [x] NEW       src/utils.py           │
│ [ ] SAME      README.md              │
│ [全选] [取消全选] [跳过相同文件]        │
├─────────────────────────────────────┤
│ 差异预览                              │
│ --- a/src/main.py                     │
│ +++ b/src/main.py                     │
│ @@ -10,3 +10,5 @@                     │
│  def hello():                         │
│  +    print("new line")               │
│  +    print("another")                │
│   return "world"                      │
└─────────────────────────────────────┘
```

### CUI

在文件选择界面增加 `d+序号` 命令（`d1`、`d2`），用 rich Syntax 渲染 diff。

---

## 核心逻辑

`core.py` 新增 `get_file_diff(workspace, backup, entry) -> str`：

| 文件状态 | 输出 |
|---|---|
| `modified` | `difflib.unified_diff` 标准 diff |
| `new` | 全文每行前加 `+` 前缀 |
| `renamed` | 文字提示"重命名文件，内容不变" |
| `same` | 空字符串 |

使用 Python 标准库 `difflib`，无需额外依赖。
