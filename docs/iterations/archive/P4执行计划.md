| Pre-3 | `files_changed` in formalize | `step_create_formal_commit()` detail 增加变更文件列表 |

### Pre-1：correlation_id

**修改文件：**
- `backend/core/history.py` — `HistoryEntry` dataclass 新增 `correlation_id: str = ""`
- `backend/core/sync_session.py` — `__init__` 生成 `self._correlation_id`，所有 `add_operation()` / `add_suggestion()` 传入
- `cli/commands.py` — 各 `_cmd_*` 方法生成一次性 correlation_id，传入 history 调用

```python
# HistoryEntry 新增字段
correlation_id: str = ""  # session 级关联 ID，同一次工作流的所有记录共享

# SyncSession.__init__
import uuid
self._correlation_id = str(uuid.uuid4())

# 所有 add_operation 调用增加 correlation_id=self._correlation_id
HistoryManager.add_operation(..., correlation_id=self._correlation_id)
```

### Pre-2：Batch push

**修改文件：**
- `backend/core/sync_session.py` — `step_push()` 改为收集所有 `synced=True, pushed=False` 的 formal commit，一次推送，全部标记 pushed

```python
def step_push(self, skip_scan: bool = False) -> tuple[bool, list[dict]]:
    targets = [fc for fc in self.formal_commits if fc.synced and not fc.pushed]
    if not targets:
        self.on_log("没有待 push 的正式 Commit")
        return False, []
    # ... push 操作 ...
    if success:
        for fc in targets:
            fc.pushed = True
        HistoryManager.add_operation(
            ..., "push", "success",
            {"commits": [f"[{fc.prefix}-{fc.number}]" for fc in targets]},
        )
```

### Pre-3：files_changed in formalize detail

**修改文件：**
- `backend/core/sync_session.py` — `step_create_formal_commit()` detail 增加 files_changed

```python
HistoryManager.add_operation(
    self.project.name, "formalize", "success",
    {"commit": f"[{prefix}-{fc.number}]",
     "source_indices": list(selected_indices),
     "files_changed": [
         {"path": e.rel_path, "status": e.status}
         for e in self.entries if e.selected
     ]},
    correlation_id=self._correlation_id,
)
```
