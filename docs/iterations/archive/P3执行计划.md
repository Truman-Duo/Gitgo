### B2：`diff_summary()` 实现

```python
# backend/core/operations/diff.py (新文件) 或 utils.py

def get_diff_summary(workspace_path, git_runner, since_hash, files) -> list[dict]:
    """返回变更文件的轻量统计摘要，不包含行级 diff。

    返回: [{"path": "...", "added": 120, "removed": 0,
            "status": "new", "top_level_symbols": ["ClassName", "func_name"]}]
    """
```

- `status`: `git diff --name-status` → `"new" | "modified" | "deleted" | "renamed"`
- `added/removed`: `git diff --stat` 解析
- `top_level_symbols`: `git diff` 输出中正则 `^[+-]\s*(class|def)\s+(\w+)` 提取，最多 10 个
- 不含行级 diff 内容 — 控制 token 量
