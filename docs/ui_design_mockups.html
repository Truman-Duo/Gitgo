DESIGN NOTES — Phase 1
1. Commit Box Fix: Long messages like e104b9d now wrap naturally instead of being clipped at 48px. Remove setMaximumHeight(48), use setWordWrap(True).
2. Authorship Toggle: New checkbox in push bar, backed by PanelState.strip_authorship: bool. Producer: AuthorshipMixin, Consumer: SyncPushMixin.
3. Template Selector: Exposes commit_format.template_name to GUI. Reads available templates from TemplateManager.list_templates().

DESIGN NOTES — Phase 2
Architecture: New GovernanceMixin registered in TAB_CLASSES. PanelState adds: contract_status: dict, integrity_score: float, lesson_count: int. All Producer: GovernanceMixin.
Data flow: GovernanceMixin calls contract.check_drift(), guard.check_integrity(), lesson.list_lessons() on tab open. Results stored in PanelState, consumed by the card widgets.
Severity states via QSS: Card border uses setProperty("severity", "warning"|"danger"|"ok") + unpolish/polish. No hardcoded colors in Python.
Threshold logic: Integrity < 80% = red border, < 95% = yellow border, >= 95% = green border. Configurable via integrity.mass_override_threshold.

DESIGN NOTES — Phase 3
Data source: state_reader.get_project_state(project) returns aggregated stats (sync count, push count, drift count, integrity score). No new Worker needed — reuse existing QTimer refresh in project_list.py.
Health color: integrity >= 95% = green bar, >= 70% = yellow, < 70% = red. Card border also changes: setProperty("health", "danger") for the red-border variant.
Click behavior: Card click = open project (same as current _enter_project(row)). Buttons use event filter to prevent card-click propagation.
Layout: QScrollArea + QVBoxLayout with card widgets. No QTableWidget. Each card is a ProjectCardWidget(QWidget) with signals: opened, syncRequested, pushRequested.

PanelState & Mixin Architecture Map
How new features integrate with existing architecture.
PanelState (explicit shared state container)
├── project: ProjectConfig          # P: main_window → C: all
├── file_tree: list[FileTreeEntry]   # P: BuilderMixin → C: CommitMixin
├── ws_commits: list[dict]           # P: CommitMixin → C: SyncPushMixin
├── formal_commits: list[dict]       # P: CommitMixin → C: SyncPushMixin
├── scan_result: dict                # P: BuilderMixin → C: all
├── strip_authorship: bool = True    # P: AuthorshipMixin → C: SyncPushMixin  ← NEW
├── template_name: str = "default"   # P: AuthorshipMixin → C: CommitMixin  ← NEW
├── contract_status: dict            # P: GovernanceMixin → C: GovernanceMixin ← NEW
├── integrity_score: float           # P: GovernanceMixin → C: GovernanceMixin ← NEW
├── lessons: list[dict]              # P: GovernanceMixin → C: GovernanceMixin ← NEW
└── governance_events: list[dict]    # P: HistoryMixin → C: HistoryMixin    ← NEW
