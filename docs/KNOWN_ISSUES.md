# 已知限制

Alpha 3 的 Windows 正式终端已获 owner 基线确认，各平台自动验证结果以相同候选的 CI 和 [Release](https://github.com/Truman-Duo/Gitgo/releases/tag/v1.0.0-alpha.3) 摘要为准；不等于跨平台完整沙箱或任意业务流程均已验证。必要关联工作发现与 Grill 增量对齐、总体质量/成本对照、完整开发任务沙箱和部分界面信息减法仍待后续。签名清单最多七天有效，发行方必须在到期前续签并递增序号，客户端过期时明确拒绝，不降低验证。范围见 [Alpha 3](ALPHA_3.md)。下列条目是来源候选的历史记录，已修复项不作为当前失败结论。

## 维护者接续候选

`feat/alpha3-integration-v1` 接续 PR #35 的 `36c1ff7`，保留作者的来源历史。维护补丁显式绑定 Windows 注册测试的可信源码适配器，补齐工作台构建依赖及发行哈希，并让构建预检和最终包冒烟实际调用文档验证器。Context 连发导航改为累积状态更新；剪贴板回归使用异步受限子进程及匹配的测试期限。

Linux 更新 worker 使用发行版自带的 bubblewrap AppArmor 配置，并先验证无特权网络命名空间能启动。它不关闭全局 userns 限制、不增加无隔离回退、不授予工具额外能力；实际原生结果以维护分支 CI 为准。历史候选出现过 `bwrap: loopback: Failed RTM_NEWADDR: Operation not permitted`，工具与委托目录存在并不证明内核/配置前提满足。

下列来源记录保留原失败事实；其中已由维护补丁处理的依赖、源码适配器和测试问题，不再作为当前源码缺口。macOS 普通 daemon、Linux 受保护 Git，以及真实业务差异升级/旧数据、正式终端和发行验收仍未完成。源码回归不能代替最终包功能或用户试用。

## Alpha3 集成候选的已查明限制（2026-10-22）

- macOS 不只是“尚未验收”：继承的安全读取后端没有 Darwin 实现，新工作区的旧会话探测也会先失败，阻断治理初始化和普通 daemon，错误为 `DAEMON_START_FAILED / GOVERNANCE_STATE_UNAVAILABLE`。不以普通文件读取或空状态绕过。
- Linux 受保护工作树、晋升和正式 Git 提交为未实现能力，返回 `GIT_BOUNDARY_UNAVAILABLE`；更新、存储、原生清理等独立能力仍需各自验证，不作全平台豁免。
- 仅由 `packaging/requirements-build.lock` 准备的构建/测试环境缺少工作台 `nbformat` 依赖闭包。Linux 更新源码测试已证实失败；最终冻结包工作台是否可用尚未独立实测，不能用 Host 启动冒烟代替。
- Windows 未注册可信 Gitgo 源码的开发子解释器无法加载 `sandbox_pytest`，六项注册测试在来源与候选均可复现。parent pytest 能导入源码不代表项目目录中的子进程能导入；个人环境注册只作为验证前提，不是产品修复或原 CI 通过证据。
- Linux 更新 CI 接入 Alpha2.1 全量 suite 时遗漏原生工具与委托环境，本轮已修正准备步骤；POSIX 搜索测试假引擎遗漏执行位也已修正。新 CI 必须自行给出结果，旧红灯保留。
- 现有双包脚本只改变版本声明，尚未覆盖不同业务/数据契约与代表性旧数据迁移。程序回滚不等于数据、配置或项目回滚，不接管已有 Inno 安装。

完整来源对照、历史失败/跳过计数、支持矩阵和维护者后续责任见[复审交接](ALPHA_3_REVIEW_HANDOFF.md)与[当前功能](IMPLEMENTATION_STATUS.md)。本轮按审查约定移交来源原有缺口，不声称补齐跨平台后端。下面的“未合入本期”仅指原 Alpha2.1 发布记录。

## Alpha 2.1 当前限制（2026-10-22）

- 普通安装、特权原生存储、Linux/macOS 实际运行与最终可见终端尚未完成本期验收；前提不足时拒绝执行，不降低隔离。操作员配置要求见[原生沙箱](NATIVE_SANDBOX.md)。
- Windows 沙箱本期支持 PowerShell；Git Bash 隔离另行跟踪。
- 管理安装/签名更新/回滚与历史缩放修复分别在 `feat/managed-update-v1`、`feat/history-resize-v1`，未合入本期。
- 经验长期效果及总体质量改善尚无充分对照；模型仍可能遗漏联动修改。必要关联工作发现与 Grill 对齐为后续 P0。

以下为先前版本的记录；其“尚未发布”、旧 Git Bash 交互验收及旧 OS 沙箱范围仅适用于原版本。当前范围以 [Alpha 2.1](ALPHA_2_1.md) 为准。

原记录日期：2026-10-11；沙箱条目于 2026-10-18 补充，其他条目的验收范围不变。以下区分当前源码与已发布预览包。

- 自动 failover 和熔断已在源码中实现并做过真实故障测试；不承诺所有错误、Provider 和中断方式均可透明恢复。
- 提问时机仍是可错的模型判断。自然架构请求中的两类漏问及时间地区澄清边界仍有未达到预期的案例，不能宣称全部语义验收通过。
- 纯 API 也能提问和采用自主委托。当前横向试验没有证明 Gitgo 在总体质量、成本或速度上更优。
- 部分旧回调和状态路径仍在渐进迁移；持久事件不等于全部信号都已统一，更不意味着外部副作用可以安全重放。
- 原生执行已有受限文件/网络及进程树资源边界，但尚无通用硬磁盘配额、完整开发项目闭环或全平台等价保证。任意高权限 Python 不能仅凭审批视为安全。当前候选、配置前提和验证范围见[沙箱摘要](SANDBOX_ARCHITECTURE.md)。
- 现有隐私检查能发现部分凭据和私有指令，但尚不能完整阻止公开资料引用私有资料。通过现有扫描不代表内容已经全面获准公开；发布仍需人工检查。
- 完整持续文档维护尚未实现。
- 本地真实模型验收延期；macOS/Linux 原生包、系统凭据适配与完整终端验收不在本次范围。
- Shift+Tab、Bun/Node 选择及运行模式属于另行处理的工作，本次不宣称完成。
- 自动更新、云端远程调度、通用 OCR 和任意格式转换不属于当前能力。
- 后台统计只覆盖保留下来的源记录；记录缺失不能补成零，统计事件数不等于对话数量或质量评分。
- 搜索分页不是工作区快照；并发文件变更可能改变页内容。外部转换器或搜索引擎缺失应报告，不应假装完整结果。
- Alpha 2 ZIP 已验证冻结运行时和真实 API，正式终端主流程已获确认；扩展 Trace 单独审阅，公开发布与 Installer 尚未完成。旧下载包的能力以对应版本说明为准。
