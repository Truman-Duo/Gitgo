# 当前功能

## Alpha3 源码集成候选与平台边界（2026-10-22）

PR #35 已组合 Alpha2.1、管理更新和历史缩放源码；产品版本仍为 `1.0.0-alpha.2.1`，不代表 Alpha3 已发行。当前候选的已证实限制和来源归因见[复审交接](ALPHA_3_REVIEW_HANDOFF.md)。

| 平台／操作 | 当前支持边界 |
| --- | --- |
| Windows 更新、受保护 Git、PowerShell 原生工具及源码注册测试 | 按私有目录、ACL、安全 SQLite 和可信源码可导入等前提验证；未注册源码时注册测试有已复现的历史缺陷；普通安装、真实 API 与正式终端仍待维护者验收 |
| Linux 更新、存储及原生进程清理 | 有独立实现与委托/原生工具前提，不能因 Git 缺口免验；管理更新新 CI 已补原生测试准备，结果以对应候选 CI 为准 |
| Linux 受保护工作树、晋升和正式 Git 提交 | 未实现受保护后端，明确报 `GIT_BOUNDARY_UNAVAILABLE`，不提供无隔离回退；不是已支持的成功路径 |
| macOS 安全读取、治理初始化和普通 daemon | 缺稳定读取后端，当前普通启动会被治理初始化拒绝，实际 CI 报 `DAEMON_START_FAILED / GOVERNANCE_STATE_UNAVAILABLE`；包可编译或 capability audit 通过不等于 daemon 可用 |
| 仅安装构建锁依赖的工作台 | 历史锁遗漏 `nbformat` 闭包；工作台源码调用已在 CI 失败，最终冻结包工作台仅为风险推断，尚未独立实测 |
| 双版本产物更新 | 现有脚本覆盖真实包安装/切换/事务机制，不证明不同业务实现、旧数据迁移或真实发行版本间兼容 |

本轮不补齐来源模块原有平台能力；真实 API、最终终端、用户试用与发行资产由维护者接续。下文保留已发布 Alpha2.1 和更早版本记录，不能代替本候选的支持矩阵。

## Alpha 2.1 当前状态（2026-10-22）

当前产品版本为 `1.0.0-alpha.2.1`，独立分支 `release/alpha2.1`，已发布[实验性预览](https://github.com/Truman-Duo/Gitgo/releases/tag/v1.0.0-alpha.2.1)。在原 Alpha 2 上补充知识收割与召回、可切换提示词实例、版本化稿纸/计算，以及统一候选执行、经验检查、精确文件提交和状态服务的沙箱整合。Windows 本期使用 PowerShell；Shell、文件、文档、注册测试、工具和子进程工作树复用受控执行边界。

已完成自动验证范围及限制见 [Alpha 2.1](ALPHA_2_1.md) 和 [测试结果](VALIDATION.md)。普通安装与特权存储尚未验收；完整 Alpha 3 还需合入管理更新与历史缩放分支，必要关联工作发现/Grill 对齐仍待后续 P0。

下文是原 Alpha 2 历史能力摘要；涉及平台和安装的旧结论不能替代上述本期限制。

更新时间：2026-10-11。范围：Alpha 2 功能分支与版本页记录的 ZIP；公开 Release 尚未发布。

## 可用能力

| 范围 | 当前行为 |
|---|---|
| 对话与任务 | 正式 Dashboard、流式消息、思考、工具、问题、审批与最终结果；支持取消和显式恢复 |
| 项目协作 | 主任务/子任务、依赖、独立 worktree、审查；不能由子任务自批结果 |
| 文件与搜索 | 读写/编辑/追加；路径与内容搜索默认使用 ripgrep，有界结果和明确回退提示 |
| Shell 与文本 | 参数向量命令、需授权的 Bash 脚本、共享环境策略；文档输入与展开限制 |
| Provider | Responses、Chat Completions、Messages 适配；能力探测、备用队列、熔断和实际模型身份 |
| 提问 | 模型发起，卡片逐题展示；答案与任务绑定，委托不替代权限批准 |
| 完成检查 | 实际回执、测试证据及交付文件检查；不能满足的要求可显式处理，缺失不伪装通过 |
| 状态 | SQLite/CAS、生命周期守卫、版本冲突检测、持久事件与恢复；部分旧通道尚未统一 |
| 自定义工具 | 组合工具逐叶校验与续跑；发明工具不因外层身份获得额外权限 |
| 终端与输入 | 自动发现、可选终端验证、下次启动生效、共享历史、复制/粘贴与重绘修复 |
| 维护与观察 | 后台可用性统计、体积/复杂度/依赖方向的非阻断告警 |

## 已覆盖的验证

后端全量 1395 passed / 2 skipped，Dashboard 173 passed / 0 failed，类型检查通过。真实 API 覆盖自动 failover、问题与答案采用、文件交付及部分权限/恢复边界。正式 Git Bash 的问题卡、交付、颜色、滚动、复制和粘贴已有人工验收。

具体范围与复测方法见 [测试结果](VALIDATION.md)。

## 尚未完成或未充分验证

- 本地实际模型接入验收延期；兼容 HTTP 服务测试不等于实际模型通过。
- macOS/Linux 原生验收、OS 沙箱及运行模式变更不在本次完成范围。
- 全量旧回调迁移及完整通用隐私引用检查尚未完成。
- 持续文档维护不是已经可用的自动功能。
- 提问必要性和方案质量仍可能判断失误；横向试验不足以证明优于纯 API。
- Alpha 2 ZIP 已构建并完成冻结与真实 API 验证，正式终端主流程已获确认；扩展 Trace 与 Installer 验收分别跟踪。

详见 [已知限制](KNOWN_ISSUES.md)。
