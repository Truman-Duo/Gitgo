# Alpha 3 基线

产品版本为 `1.0.0-alpha.3`，Windows 文件版本为 `1.0.0.4`。本期整合 Alpha 2.1、PR #32 管理更新与回滚、PR #31 历史缩放及页面选择可见性，以及 PR #35 的融合修正。保留原贡献者提交历史。

## 发布范围

owner 已于 2026-10-24 确认当前正式 Dashboard 试用版本作为 Alpha 3 基线。发布仍须通过下列全部平台门槛；发行资产的验证摘要记录实际提交、树和结果，失败候选不发布。Windows x64 提供管理安装 ZIP；源码支持范围与各平台自动验证分别记录。沙箱是统一权限与安全边界的初版基础设施，不承诺完整开发任务沙箱或全平台等价隔离。必需隔离与权威状态缺失时明确拒绝，不回退到无隔离执行。

管理更新具备签名、受控安装与回滚机制。Windows 发行包固定正式 Ed25519 公钥，预览清单及签名单独通过 GitHub Release 的 `updates-preview` 提供；未发行稳定版前不配置稳定渠道，不将 Alpha 包提供给稳定渠道。私钥不随源码和包发布。现有双包验证不证明任意旧业务数据可以迁移或回滚，不自动接管既有普通安装。建议保留原安装及数据备份，使用独立预览目录。

## 验证门槛

Windows 源码全量、原生沙箱与受保护存储、冻结更新与回滚、最终 ZIP/Host 连续性、Dashboard、跨平台输入契约、隐私和 PR 对齐检查全部为必需门槛。失败、取消和非预期跳过不能算通过。发布包包含源码身份、文件清单和校验摘要；具体结果以相同候选的 CI 与发行验证摘要为准。

Linux 原生与更新、Linux/macOS 打包及独立原生验收同为必需门槛；所有结果写入门槛摘要，任一失败、取消或非预期跳过都不放行。此前 Windows-only 候选的诊断豁免已经撤回。自动测试不能替代 owner 的实际试用和发布确认。

## 已知限制

- macOS 对象读取后端正在以 macOS 26 的内核 beneath/no-symlink 约束验收。更早内核若不支持该约束会明确拒绝，不能以普通路径读取降级；普通 daemon 和最终包仍须各自验证。此读取后端不等于完整 macOS 工具沙箱。
- Linux 受保护 Git 已接入私有挂载命名空间、封存配置快照与目录描述符绑定，正在进行完整业务与最终包验收。这是受信任 Git 服务的边界，不是通用工具沙箱；需要 root 拥有的 bubblewrap 0.11.1 或更新版本及无特权用户命名空间。配置声明 worktreeConfig 时要求对应配置文件已存在，缺失时明确拒绝，不能在执行前临时出现未经审核的文件。
- Windows 完整正式终端已交由 owner 试用并获本次基线确认；真实模型已覆盖主子进程协作、连续会话与冷恢复侧讨论。此小样本不证明任意任务可靠性，也不替代其他平台的人工终端验收。
- 沙箱仍有开发任务持久化准入、硬磁盘配额、完整成果验证和其他平台后端等后续工作，见[已知限制](KNOWN_ISSUES.md)。

## 基线与回退

Alpha 2 原 master 保留为 `release/alpha2`；Alpha 2.1 保留为 `release/alpha2.1` 及已有发行标签。Alpha 3 通过 PR 合入 master，另保留 `release/alpha3` 和 `v1.0.0-alpha.3`。删除已整合功能分支不删除其提交或原作者历史。程序版本回退不等于数据库与项目内容回退。
