# macOS 原生执行和受保护 Git

本页说明 [Issue #45](https://github.com/Truman-Duo/Gitgo/issues/45) 第四阶段的开发候选。普通用户运行 Gitgo，管理员为选定项目安装独立辅助服务。服务使用 macOS 原生机制执行任务，虚拟机用于验收。生产能力默认关闭。

## 项目授权与任务生命周期

- 辅助服务以固定系统入口运行。客户端凭据绑定操作员 UID、登记的项目对象、有效期和启动会话。重启后由管理员在清理核对通过后明确重新授权。服务常驻不自动续期。
- 每次任务分配独立低权限 UID，由 launchd 监督。工作区视图和资源策略由可信 Host 与辅助服务确定。取消、超时、权限撤回和调用中断后，监督器核对该 UID 关联的进程并完成清理，后台进程离开原进程组也适用。
- 启动和调用记录支持监督器崩溃、服务重启及跨系统重启核对。已启动但结果未知的调用保留待处理记录，恢复只核对状态，避免自动重放。
- CPU 计量使用 launchd 为任务建立的资源账本。内存评估结合存活进程采样及单进程已观测峰值。仍可能漏掉两次采样之间退出的短时内存尖峰，资源限制按已验证的观测范围报告。

## 受保护 Git 与发布

通过阶段二的 Rust 稳定对象读取固定 Git 对象。管理员授权的项目与完整提交 ID 对应受保护视图；Host 从该视图创建任务工作树，校验对象、索引和任务结果，再封存准备发布的结果。Dashboard 通过原有权限流程请求针对该结果的一次授权。等待和拒绝时不改项目，批准后使用持久记录确认发布结果。重复操作只核对已有结果。外部改动或效果未知时停止发布并保留记录。

支持范围为明确定义的 SHA-1 Git 对象、固定基线和有界线性发布。发布范围限于已有安全父目录中的普通文件。任意 Git 工作区状态、非线性合并及新增父目录应用需另行验收。

## 内部安装的完整包摘要

按 [打包和初装步骤](../packaging/README.md#macos-stage-four-managed-install-acceptance) 构建并解包。管理员首次运行的入口应来自已核对的可信构建。用可信源码中的 `scripts/macos_helper_digest.py` 在普通用户下读取辅助服务目录，核对结果与独立构建记录，再向管理员安装命令传入 `--expected-bundle-sha256`。

摘要覆盖完整目录内容、文件执行位和内部链接。安装器在复制前、复制后及封存后检查，root 专属回执保存已确认的摘要。固定管理员入口、服务启动、升级和恢复使用同一封存检查。依赖或回执损坏时拒绝操作，保留现有服务和记录。

升级需明确核对候选摘要。固定摘要的服务拒绝切换到仅使用旧式本地许可的镜像。已安装的相同库存可以凭明确摘要升级回执。新服务启动失败时恢复已记录的前驱；旧软件不认识的回执或协议操作会被拒绝。管理员可显式选定较旧包。正式发布者认证、密钥轮换及远程自动接受新 helper 留待公开发行。

## 验证范围

- 多平台组合 CI 使用前置阶段的审查提交。通过范围包括 Windows 源码、原生及最终包回归，Linux 两种架构的包与升级回滚，以及 macOS ARM64 源码回归和独立打包验收。[运行 43616615059](https://github.com/hanyujason/Gitgo/actions/runs/43616615059)
- 此前内部构建在开启 SIP 的 macOS 26.6.2 ARM64 虚拟机通过普通用户任务、Dashboard 审批、故障清理、摘要固定、升级恢复、重启再授权以及卸载。固定摘要验收所用产品构建为 `2b555020d6d0ab1ae0548e245ad896d134f7e2a3`，归档 SHA-256 为 `87eb0d9ee4796520c118dcec2cc670fb44b17ca0aeef8799d91d0352e5f920ae`。涉及真实 Git 审批和 App 跨版本更新的历史证据来自各自单独记录的组合包，当前候选的常规构建沿用目标分支的更新器。
- 需重复完整包摘要验收时，在 SIP 开启的可丢弃 macOS VM 使用源码中的 `scripts/check_macos_helper_pin.py`。以管理员运行时传入 `--run --bundle PATH --expected-bundle-sha256 SHA256`，保留报告，重启来宾。使用同一可信源码和 Python venv 运行 `--run --resume REPORT`，核对自动启动、重新授权和卸载。虚拟机安装验收与 CI 的普通用户安装、运行时和能力审计分别记录。
- 其他 macOS 版本和架构的辅助服务生命周期、公开发行及正式可见终端仍需分别验证。
