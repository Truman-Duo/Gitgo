# 审批文件读取：授权与恢复

更新日期：2026-10-18。适用于声明 `read_existing_file` 的原生 `read_file` / `file_read`。
普通工作区读取不因此增加新的用户确认，读取限制见[文件读取](STABLE_FILE_READ.md)。

## 批准什么

审批展示文件资源和调用参数，并绑定工作区、读取根及文件对象、工具版本和期限。
任务授权只允许相同参数、相同对象的重复读取，不自动覆盖另一文件或另一个行窗口。
需要扩大范围时重新申请；批准不改变 OS 文件权限。

Host 在审批等待期间保留有期限的元数据对象保护，不读取目标内容。
每个 process 最多保留 64 项，最长 30 分钟。拒绝、取消、到期或任务结束时撤销新准入资格。
实际准入及原生打开后均核对对象身份；同名文件、父目录或读取根被替换时不能借用原批准。

## 执行与释放

单次授权在实际准入只消费一次。原生子进程自行在 OS 边界内打开并读取对象，不继承额外 Host 文件句柄，也不接收模型提供的私有读取计划。
逻辑批准不能使它读取原本被 AppContainer/namespace 拒绝的 Host 文件。

撤销后不再接受新调用。已启动调用仍保留所需对象引用，直到原生清理得到确认；
清理未知保留引用和资源债务，不以“已发出终止请求”代替释放条件。

## 恢复与限制

Host 重启不能恢复原来的活跃句柄；旧请求、文件 ID 或序列化 grant 不能复活执行权，需要新审批。
未知调用不自动重放。审批消费仍是进程内原子性，不是跨数据库与 OS 的原子启动事务。

对象相同不保证内容不变；该接口不覆盖目录枚举、写入、创建、删除、Git 或完整挂载保护，
也不代表[完整有效计划](EFFECTIVE_EXECUTION_PLAN.md)已经启用。

## 验证

用例覆盖单次/任务授权、并发一次性消费、同名及父目录替换、过期/取消、活跃引用释放、重启失效和私有字段篡改。
文件系统、原生源码与实际 frozen 验收分别记录；协议测试不代替 OS 隔离测试。
版本与证据范围统一见[验证摘要](SANDBOX_ARCHITECTURE.md#验证版本与结果)。
