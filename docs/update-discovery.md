# 更新检查与下载验证

关联 [Issue 21](https://github.com/Truman-Duo/Gitgo/issues/21)。[管理安装](managed-installation.md)可经首页 `/update` 手动检查、确认下载，再独立确认交接。默认不带正式发行信任；未配置时不联网，普通启动和刷新本地状态也不检查更新。

## 验证行为

- 只信任初始安装固定的 Ed25519 公钥，先验证清单精确字节的独立签名，再解析内容。SHA256 不代替发布者签名。
- stable / preview 分开；精确匹配产品、平台、架构及最低更新器版本。普通更新不降级，stable 不接受预发布版本。
- 拒绝不支持的 schema、重复字段、非法数字、过大或过深清单。检查发布时间、最多七天的有效期及渠道防重放记录。
- 拒绝发布序号倒退、同序号改写、同版本换包；下载失败或取消不降低持久记录。
- 数据兼容描述必须与安装及实际包匹配；缺失或变化时保守拒绝，不迁移用户数据库。写入模块指纹包含 Python minor，普通代码变动也可能使候选不兼容。

## 传输与解压

HTTPS 保留证书和主机名验证，支持本地代理/CA。只访问明确允许的发布域名，逐跳检查最多三次重定向；不继承应用认证或 Cookie，不转发服务端 Cookie。只接受完整 HTTP 200 和原始未额外压缩响应，不做断点续传。

默认单项网络超时 15 秒，总传输时限 600 秒；下载流核对大小和 SHA256，完成后重新验证签名和有效期。网络/代理、取消、磁盘及包损坏错误不会生成可安装结果。

包在安装登记绑定的独立私有目录中展开。逐项检查路径、大小写/Unicode 冲突、链接及父节点；拒绝越界路径、设备文件、硬链接、危险链接和 Windows 数据流。支持 Windows ZIP 及 Unix tar.gz 的现有打包格式；ZIP64、多卷和加密 ZIP 不支持。

默认限制为 10,000 条目、4 GiB 文件总量、2 GiB 单文件、8 MiB 元数据、32 层路径、1,000 倍展开比例及 300 秒处理时限；tar 扩展记录另限 1 MiB。临时 tar、下载包与最终文件会同时占用空间，这些限制不等于 OS 级资源配额。

下载验证完成不表示已安装或已授权执行。交接前仍重新核对完整 product/build 清单、文件 inventory、源码与数据证据，并取得运行门禁。失败只清理本次明确创建且身份未变的内容；强制退出可能留下私有残片，不自动采用或清除未知目录。

## 覆盖范围

测试包含一次性 CA、真实回环 TLS、证书/主机名拒绝、CONNECT 代理、凭据隔离及中断/取消；注入传输还覆盖签名和包错误。它们不代表生产 CDN、企业代理或正式签名发行配置已验收。

使用、策略字段及平台限制见 [手动更新](update-preparation.md)、[Windows](windows-managed-update.md)、[Linux](linux-managed-update.md)。临时目录由同一用户控制；更新验证不是执行恶意代码的 OS 沙箱。
