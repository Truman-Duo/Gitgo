## F-1：左侧文件树（LSB）全局化 — ⚠️ 最高风险，最后执行

### 目标

LSB 当前是 `ws_hsplitter[0]`，仅 Workshop Tab 可见。应提升为项目级常驻面板，与 QStackedWidget 平级。

### 实现方案

```python
# main_window.py — _open_project() 后的顶层布局
body_row = QHBoxLayout()
body_row.setContentsMargins(0, 0, 0, 0)
body_row.setSpacing(0)

self.tab_stack = QStackedWidget()        # 4 Tab 内容区

body_row.addWidget(self.lsb)
body_row.addWidget(self.tab_stack)
body_row.addWidget(self.rsb)             # RSB 同理平级
```

### 影响范围

- `builder.py` `_build_workshop_tab` — ws_hsplitter 从三栏缩减为两栏（ctr_widget + right_splitter）
- `explorer.py` — ExplorerMixin 方法当前通过 `self.` 引用 file_tree/diff_preview，需重新梳理归属
- `main_window.py` — `_open_project` 创建 LSB，`_back_to_list` 销毁 LSB（需要极度谨慎的创建/销毁时机）
- LSB 需要 `set_context()` 方法：Workshop Tab → 显示 workspace 文件，Incoming Tab → 显示 trial 文件

### Claude 反馈

- **正确性**：设计逻辑完全正确，LSB 本就应该是项目级
- **关键风险**：之前返回崩溃的教训说明创建/销毁时机极其敏感。`_back_to_list` 中 LSB 的销毁顺序必须在 workspace 之前

## F-2：Commit 卡片三层信息结构 — ✅ 低风险，首发

### 目标

Workspace 卡片从两层（title + subtitle）升级为三层：

```
[type badge]   feat                ← 9px, weight 500, blue_txt / teal_txt
[摘要]         add SSH file adapter ← 11px, t.txt, padding-right 20px
[meta]         today · duo          ← 10px, t.txt3
[checkbox]     ✓ (右上角绝对定位)   ← 14×14px
```

### 实现方案

```python
class WorkspaceCommitBox(CommitBox):
    def __init__(self, idx, commit_type, summary, meta, parent=None):
        lo = QVBoxLayout(self)
        lo.setContentsMargins(10, 6, 10, 6)
        lo.setSpacing(2)

        self.type_lbl = QLabel(commit_type.lower())
        self.type_lbl.setObjectName("ws_type_badge")

        self.summary_lbl = QLabel(summary)
        self.summary_lbl.setWordWrap(True)

        self.meta_lbl = QLabel(meta)

        lo.addWidget(self.type_lbl)
        lo.addWidget(self.summary_lbl)
        lo.addWidget(self.meta_lbl)

        # checkbox 右上角绝对定位
        self.cb = QLabel(self)
        self.cb.setFixedSize(14, 14)
        self.cb.setAlignment(Qt.AlignCenter)
        self.cb.move(self.width() - 21, 6)

    def resizeEvent(self, e):
        super().resizeEvent(e)
        self.cb.move(self.width() - 21, 6)

    def set_selected(self, v: bool):
        self.selected = v
        self.cb.setText("✓" if v else "")
        self.cb.setProperty("checked", v)
        self.cb.style().polish(self.cb)
        self._apply_style()
```

### Formal 卡片竖线（paintEvent 实现）

QSS `border-left` 会被 QFrame.frameShape 干扰，必须用 paintEvent：

```python
class FormalCommitBox(CommitBox):
    def paintEvent(self, e):
        super().paintEvent(e)
        p = QPainter(self)
        color = QColor(self._accent_color())   # blue / teal / amber
        p.fillRect(0, 0, 3, self.height(), color)
        p.end()

    def _accent_color(self):
        if self._is_incoming: return get_theme()["amber"]
        if self._synced:       return get_theme()["teal"]
        return get_theme()["blue"]
```

### Claude 反馈

- **可行性**：仅替换 CommitBox 内部布局，外部接口不变，风险极低
- **注意**：`resizeEvent` 中需 `setMinimumWidth` 保证 checkbox 不被压到 0
- **注意**：`style().polish()` 方案比 `setStyleSheet()` 轻量，是正确的 QSS 动态刷新方式

## F-4：非活动 Formal 卡片 opacity — ✅ 低风险

### 目标

选中一个 formal commit 时，其他 formal 卡片半透明（opacity 0.65）。

### 实现方案

```python
def _set_active_formal(self, active_idx: int):
    for i, box in enumerate(self._formal_boxes):
        effect = QGraphicsOpacityEffect(box)
        effect.setOpacity(1.0 if i == active_idx else 0.65)
        box.setGraphicsEffect(effect)
```

### Claude 反馈

- **关键坑**：不能复用同一个 effect 实例给多个 widget，必须每次 new
- **关键坑**：主题切换后需重新调用（`_apply_theme_colors` 中追加）
- **历史教训**：我们之前在 `_animate_page` 中因 GC 回收 effect 导致 opacity 卡 0，这里同样要注意 effect 生命周期

## F-5：Incoming Tab 标签橙色圆点 — ✅ 低风险

### 目标

有未处理的 incoming 数据时，Tab 标签右侧显示 5×5px 橙色圆点。

### 实现方案

```python
incoming_tab_widget = QWidget()
tab_lo = QHBoxLayout(incoming_tab_widget)
tab_lo.setContentsMargins(0, 0, 0, 0)
tab_lo.setSpacing(4)

tab_lo.addWidget(QLabel("Incoming"))

self.incoming_dot = QLabel()
self.incoming_dot.setFixedSize(5, 5)
self.incoming_dot.setStyleSheet(
    f"border-radius: 2px; background: {get_theme()['amber_txt']};"
)
self.incoming_dot.setVisible(False)   # 有数据时 setVisible(True)
tab_lo.addWidget(self.incoming_dot)

self.tab_bar.addTab("")
self.tab_bar.setTabButton(1, QTabBar.LeftSide, incoming_tab_widget)
```

### Claude 反馈

- `setTabButton` 替换 tab 文字内容，需先 `addTab("")` 设空字符串
- QSS 中已有的 `QTabBar::tab` padding 可能影响 setTabButton widget 定位
