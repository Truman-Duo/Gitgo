# 终端选择与历史

## 选择终端

首次启动在 General 的 Terminal 行显示自动发现的选项。左右切换、Enter 保存、R 重新扫描；发现或身份验证失败会显示原因，不应手动伪造一个可用路径。

Git Bash 选项可能区分 MinTTY 与 Windows console。可用性由当前安装、参考版本及系统条件决定；找到名为 bash 的程序不等于验证通过。未知或被修改的安装会明确提示。

初次保存可打开所选终端。以后在 `/config → General` 更改时当前窗口继续运行，新选择在下次启动生效。显式 `--attached` 保持已附着终端。

## 历史与关闭

PowerShell 与 Git Bash 使用相同配置、项目身份和状态目录，所以终端只是界面载体，不应分开保存会话。明确隔离的数据环境会有独立历史；测试窗口可能故意使用临时数据。

新版本对同一数据环境的重复产品实例提供占用错误，但不能保证所有旧版本或外部写入者都受同一锁约束。切换终端前正常关闭旧窗口；失败提示应保留可读。

## 输入与显示

正文与思考使用不同亮度，已回答问题可收起/展开。方案可滚动，拖选松开后可复制；单行粘贴不应追加空行，原有多行仍保留。终端宽高调整后仍应保持可用。

当前源码在真实 Git Bash 已通过上述人工验收。新打包版本与其他终端仍需分别验证，详见 [测试结果](VALIDATION.md)。

终端承载界面，不决定 Agent 使用哪种命令工具；参数向量命令与经审批的 Bash 脚本有各自执行规则。
