## 候选范围

| 责任范围 | 已有实现 | 对齐时关注 |
| --- | --- | --- |
| 工程实践 | Host 类型化依赖/证据工作流、现有决策与完成门禁、事件/工具通知、上下文与 BTW 的存储绑定 | 审批消费时机、组合工具逐叶检查、证据与真实效果、旧调用对象兼容 |

本轮没有完成多 Provider 熔断/本地模型、Bun/Node 迁移与运行模式、原始 Windows 10 cmd 缩放崩溃、项目列表 running 投影，也没有实现多人多仓库工作流的后端/前端。详见 [进展表](usability-roadmap.md)。

- 生成的 exe、统计库、用户配置和诊断数据不随源代码提交。本次不发布安装器或更新既有 Release。

## 与外部贡献的交叉边界

读取到的沙箱 PR [#25](https://github.com/Truman-Duo/Gitgo/pull/25) 涉及 executor、tool_pipeline、errors、tools/catalog 与 workspace_tools 等共同入口。其描述提出 Windows shell_script 从 Bash 改为 PowerShell；这与本轮验证 Bash 的执行语义有关，也与“选择哪一种终端打开前端”不同。仅消除文本冲突不能完成整合，需明确 Shell 协议、授权参数与执行收据兼容，再重新验证源码与 frozen 路径。
